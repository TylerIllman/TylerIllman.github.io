Python API#

This page describes the Python interface of FIRNA: the pipeline classes, whose methods run the steps, and the data structures and functions that the steps use. The firna commands call the same methods, so a call from Python and the corresponding command produce the same files.

Synopsis#

Call the steps of a pipeline class:

from firna import DatasetBuilder

builder = DatasetBuilder('data')
builder.seed_scan()
builder.link_families()
builder.find_components()
builder.components()

Work with data structures directly:

from firna.api import ReferenceCollection, HitTable, find_hits, evaluate_family, family_means

references = ReferenceCollection.read_archiveii('data/archiveii/archiveii.parquet', subset='RNaseP')
table_hits = HitTable.read('data/scans/archiveii-RNaseP.tbl')
hits = find_hits(table_hits, references, best_family_only=True)
results = evaluate_family('RF00010', hits)
family_means(results)

Description#

The tasks page shows how to complete each task, from Python and from the command line, and Classes states what each class is for. The interface has two levels. The pipeline classes and their steps (see Pipeline classes) run whole operations on a data folder and read and write files. The data structures and functions (see Data structures and Functions) work on objects in memory. A reader converts a file to a data structure, so data from another source can be used by constructing the structures directly. For example, a HitTable can hold Hit objects read from a cmscan table by HitTable.read or constructed from a DataFrame.

Modules#

Module

Contents

firna.pipelines

StructureBuilder, DatasetBuilder and ConsensusBenchmark, with one method for each command.

firna.dataset

DatasetConfig, row filters and the writer of the parquet files.

firna.structures

Structure notation, base pairs, hit coordinates and scoring.

firna.io

The data structures, and reading and writing of their files.

firna.rfam

Readers of the files that Rfam publishes.

firna.downloads

Fetching Rfam’s files and the data this project hosts.

firna.tools

Wrappers for cmscan, cmalign, R-scape, Easel and RNAfold.

firna.jobs

The work of the steps, including the per-family functions that run in worker processes.

firna.api

The public data structures, functions and pipeline classes in one namespace.
