Classes#

This page states what each main class is for and when to use it. Each class name links to its attributes and methods. Small records, such as Hit and Score, are listed in Data structures.

Pipeline classes#

A pipeline class holds the steps of one job on a data folder, as methods. Each step generates one command. Pipeline classes gives the order to call them in.

Class

Used for

StructureBuilder

Getting the structures of Rfam families: downloads, alignments, CaCoFold folds and structure tables, and giving structures to new sequences with predict.

DatasetBuilder

Building a dataset whose splits never share a family, and reading it with rows and summary.

ConsensusBenchmark

Scoring consensus structures against known structures.

Settings and paths#

Class

Used for

DatasetConfig

Reading and changing a dataset’s settings: its stages, sources, ratios, splits and filters. It is the file dataset-config.json as an object.

ProjectLayout

Finding the default path of every file in the data folder.

Data classes#

A data class holds data in memory, with Thing.read(path) to load it from a file and thing.write(path) to save it where it can be saved.

Class

Used for

HitTable

Reading a cmscan table, and choosing between families that compete for a sequence or a region.

ReferenceCollection

Loading RNA3DB, ArchiveII or a table of known structures, and choosing the RNAs and windows to score.

StructureTable

Holding and writing rows of sequence and structure, to add your own structures to a dataset or to read a family’s table.

StructureLibrary

Finding each family’s consensus structures in a folder. Point it at any method’s output to score that method.

ConsensusEvaluation

Reading a finished evaluate-consensus run, and listing the families in which a library structure beats a baseline.

firna.pipelines.StructureBuilder

The steps that get the structures of Rfam families.

firna.pipelines.DatasetBuilder

The steps that build the family-informed dataset, so that related RNAs never straddle the split.

firna.pipelines.ConsensusBenchmark

The steps that score consensus structures against known ones.

firna.dataset.dataset_config.DatasetConfig

The settings of a dataset, saved in its config file: its stages, sources, ratios, splits and filters.

firna.layout.ProjectLayout

The standard paths under one data folder.

firna.io.hits.HitTable

Family hits, kept in the order they were added.

firna.io.references.ReferenceCollection

Reference RNAs keyed by name, as read from a source or added by hand.

firna.io.structure_tables.StructureTable

Structures held in memory, as StructureRows, to add to, remove from and write out as tables.

firna.structures.library.StructureLibrary

A structure folder laid out as <folder>/<family>/<structure>/<file>.sto.

firna.io.consensus_evaluation.ConsensusEvaluation

The results of one saved run, keyed by family, as a read-only dictionary of lists of HitResults.
