Pipeline classes#

A pipeline class holds the steps of one job on a data folder, with each step as a method. A job is completed by calling its steps one after another, in the order given below for each class. No method runs them all, so a script states every step and its options. Classes states what every class is for.

Class

Used for

StructureBuilder

Getting structures from Rfam.

DatasetBuilder

Building a dataset whose splits never share a family, and reading it.

ConsensusBenchmark

Scoring consensus structures against known structures.

Creating a pipeline class#

StructureBuilder(data_dir=None, *, report=None, interface='python')
ConsensusBenchmark(data_dir=None, *, report=None, interface='python')
DatasetBuilder(data_dir=None, *, dataset_config=None, report=None, interface='python')

data_dir is the data folder. Without one, the class uses $FIRNA_DATA, else ./data. Classes given the same folder read and write the same files. report receives each progress message. Each class has the attribute layout, a ProjectLayout that gives the default path of every file, and the method paths(), which returns those paths as a DataFrame with whether each exists.

Create the data folder once before the first step, with the function that firna init-data-folder uses. With download=True it fetches the missing shared Rfam files and presses Rfam.cm. It returns a table of the shared files.

from firna.setup import init

init('data', download=True)

StructureBuilder#

StructureBuilder gets the structures of Rfam families. Call its steps in this order.

Order

Method

Command

Result

1

download_data

firna download-data

The Rfam files and the alignments of each family.

2

build_alignments

firna structures build-alignments

The seed, full and seed+full MSAs of each family.

3

run_cacofold

firna structures run-cacofold

The CaCoFold structures of each MSA.

4

extract

firna structures extract

The structure of every sequence, from the consensus of its MSA.

 
from firna import StructureBuilder

structures = StructureBuilder('data')
families = ['RF00005']
structures.download_data(families=families)
structures.build_alignments(families=families)
structures.run_cacofold(families=families)
structures.extract(families=families)

predict is separate from this order, because it takes sequences of its own. It gives them the structures of the families they hit.

structures.predict('queries.fa', best_family_only=True, out='results/my_queries')

DatasetBuilder#

DatasetBuilder builds a dataset whose splits never share a family. Call its steps in this order, after the sources are listed with make_config, which is described under The dataset settings.

Order

Method

Command

Result

1

seed_scan

firna scan-sequences --fasta data/scans/seeds.fa --mode rfam

The scan of the seed sequences against Rfam.

2

link_families

firna dataset link-families

The links between families.

3

find_components

firna dataset find-components

The component of each family.

4

split_components

firna dataset split-components

The split of each component, in assignment.tsv.

5

build

firna dataset build

The parquet files.

 
from firna import DatasetBuilder

builder = DatasetBuilder('data')
builder.download_data(include=['core', 'seed-fasta'])
builder.make_config(['pretrain:rfam=data/structures'])
builder.seed_scan()
builder.link_families()
builder.find_components(min_fraction=0.5)
builder.split_components()
builder.build()
builder.rows('pretrain', 'train')

make_assignment runs link_families, find_components and split_components in one call, with the settings of all three. download_data(include=['scans']) fetches finished scan tables in place of seed_scan.

builder.download_data(include=['core', 'scans'])
builder.make_assignment(min_fraction=0.5)
builder.build()

The other steps prepare input. seed_scan is scan_sequences with fasta and mode set for the seed sequences, and scan_sequences takes any other input, such as reference structures. download_data writes the seed FASTA that seed_scan reads, with include=['seed-fasta'], and make_seed_fasta writes the same file from Rfam.seed.

ConsensusBenchmark#

ConsensusBenchmark scores consensus structures against known structures. Call its steps in this order. The hits table comes from DatasetBuilder.scan_sequences or firna scan-sequences.

Order

Method

Command

Result

1

find_missing_residues

firna benchmark find-missing-residues

The unresolved residues of the reference chains. It applies only to RNA3DB and can be left out for other references.

2

make_set

firna benchmark make-set

The reference RNAs and their scoring windows.

3

evaluate_consensus

firna benchmark evaluate-consensus

The scores of every structure, with the F1 score and the MCC.

 
from firna import ConsensusBenchmark

benchmark = ConsensusBenchmark('data')
benchmark.find_missing_residues()
benchmark.make_set(missing_residues='data/missing_residues.tsv')
benchmark.evaluate_consensus(families=['RF00005'], hits_table='data/scans/rna3db.tbl')

compare is separate from this order. It reads a finished evaluation and lays the structures of chosen hits onto each chain, for inspection by eye.

benchmark.compare(families=['RF00005'], out='rf00005.sto')

Steps#

The keywords of a step are the options of the command of the same name, with hyphens written as underscores, and they are given when the step is called. help(builder.link_families) lists them.

builder.link_families(link_evalue=0.001)
builder.find_components(min_fraction=0.5, dry_run=True)

A step that writes one output, which is called a stage, returns the path of that output. It keeps an output that was made from the same inputs and options. If the output was made from different ones, the call raises FileExistsError unless overwrite=True. With dry_run=True the stage prints what it would read and write, and whether the output is current, and writes nothing. A step raises an exception for an error and never exits the process. Values that do not make sense together raise UsageError, a subclass of ValueError.

The dataset settings#

DatasetBuilder.make_config writes the settings of a dataset to dataset/dataset-config.json, and DatasetBuilder.config reads them as a DatasetConfig. A change made with set_params is saved at once, so the commands use it.

builder.make_config(['pretrain:rfam=data/structures/original',
                     'finetune:archiveii=data/archiveii/archiveii.parquet'])
config = builder.config
config.set_params(stages__pretrain__ratios='90:5:5', filters__max_length=1000)
print(config)

Member

Description

builder.make_config(sources, ratios=None, *, splits=None, filters=None, member_evalue=None, overwrite=False)

Writes the config from a list of sources, each written STAGE:NAME=PATH[,scan=PATH] with any stage name, splits naming the splits and ratios giving each stage’s numbers as in firna dataset make-config. Raises FileExistsError if the config exists and overwrite is false, and ValueError if a source is not valid.

config.get_params(), config.set_params(**values)

All settings in one dict with names such as stages__pretrain__ratios and filters__max_length, and a way to change them. A value is checked when it is set.

config.splits, config.stage_names

The names of the splits and of the stages.

config.stages, config.stage(name)

The ratios and sources of the stages.

config.sources, config.ratios, config.filters, config.member_evalue

The other settings.

config.path

The config file.

DatasetConfig.read(path), config.write(path=None)

Reads a config file, or the defaults if it does not exist, and writes one.

DatasetBuilder('data', dataset_config='data/datasets/a/dataset-config.json') uses another config file, for a second dataset in one data folder. Its assignment, manifest and rows are kept beside the file.

The built dataset#

These methods read what build wrote. They raise FileNotFoundError if nothing was built.

builder.summary()
builder.rows('pretrain', 'train')
builder.rows('finetune', family='RF00005', columns=['name', 'sequence', 'structure'])

Member

Description

rows(stage, split=None, *, family=None, columns=None)

Reads rows of a stage as a DataFrame, filtered by split and family before they are loaded. Raises KeyError if the dataset has no such stage or split.

summary()

A DataFrame of the number of rows in each stage and split.

manifest

The manifest of the build as a dict.

The family graph#

These methods read the graph that the dataset steps wrote. They do not run any step.

Member

Description

family(family)

Returns a dict with the family’s component, the families of that component, its split, and the links that leave and reach it. Raises KeyError if the family is not in the components table.

links()

Returns the links as a DataFrame.

components()

Returns each family with its component and the size of the component.

assignment()

Returns each unit with its name, component, split and the rows of each source.

family_graph(min_fraction=0.2, link_evalue=None, *, min_sequences=None)

Returns a networkx.Graph of the linked families, with the component and split of each as node attributes.

Messages#

Progress messages are sent to the firna logger, which writes to standard error. To send them elsewhere, pass report to the class or configure the logger with the logging module. The module firna.logs provides configure(stream=None, level=logging.INFO).
