Reading data#

Function

Returns

HitTable.read(path, family=None, significant_only=True)

A HitTable from a cmscan --tblout table; see Data structures

ReferenceCollection.read(path, subset=None, names=None)

A ReferenceCollection from RNA3DB annotations, ArchiveII’s parquet file or a reference table, as the commands read them; see Data structures and Reference structures

read_sequences(query, name='query')

dict[str, str] from a FASTA file, or one sequence

read_benchmark_set(path)

dict[str, (start, end)] from a table written by firna benchmark make-set

read_missing_residues(path)

dict[str, list[bool]], each chain’s missing residues, from a table written by firna benchmark find-missing-residues

ConsensusEvaluation.read(run_dir)

The HitResults of a saved firna benchmark evaluate-consensus run, by family

read_seed_structure(seed_path, family)

(name, RF, SS_cons) of a family in Rfam.seed

Choosing hits#

Function

Does

find_missing_residues(names, mmcif_dir)

Reads chains’ missing residues from mmCIF files. Returns {name: list[bool]} and {name: reason} for the chains not found.

window_around_missing(missing, min_gap=3)

One chain’s scoring window from its missing residues. Returns (start, end) and None, or None and the reason it is left out.

apply_windows(hits, windows)

Gives each ReferenceHit its RNA’s window and drops hits outside it. Returns the kept hits and the number dropped.

require_coverage(hits, min_coverage)

Keeps the ReferenceHits covering at least this fraction of their window, such as 0.95. Returns the kept hits and the number dropped.

find_hits(hits, references, family=None, best_family_only=False, windows='auto', min_coverage=0.0)

ReferenceCollection.match, HitTable.best_family_only, ReferenceCollection.scoring_windows, apply_windows and require_coverage together, as firna benchmark evaluate-consensus applies them. hits may be a HitTable, a list of Hits or a table path.

select_families(selectors, available)

Expands selectors such as RF00005, 30-3000 or all.

choose(items, families, hits)

Keeps the items chosen by family selectors and HitSelectors, as firna benchmark compare --families and --hits do.

Running steps#

Function

Does

scan(references, out)

Scans the RNAs against Rfam.cm with cmscan, writing the table to out, and returns its significant Hits.

evaluate_family(family, hits, include=None, reference_layer='secondary', fold=None, structure_dir=None)

Scores the CM’s structure, Rfam’s seed structure and each library structure on a family’s ReferenceHits, with the default data paths. structure_dir reads another method’s structures in place of the newest CaCoFold run. fold=['rnafold'] also folds each hit on its own. Returns list[HitResult].

evaluate_hits(family, hits, structures, cm_path, rfam_seed=None, reference_layer='secondary', fold=None, label_prefix='')

The same, with every input given explicitly. label_prefix starts the labels of the library structures.

fold(sequences, method) in firna.tools.folding

Folds {name: sequence} with a program from FOLDERS, such as rnafold, and returns {name: structure}.

Summaries and output#

Function

Returns

family_means(results)

Each structure’s mean MCC over a family’s hits, as (straddling pairs penalised, ignored)

improved_family(results, min_gain=0.0, baseline='rfam_seed')

Whether a library structure’s mean MCC beats the baseline’s by more than min_gain

structure_blocks(family, results)

The Stockholm blocks of firna benchmark compare, as a list of strings

write_eval_structures(path, family, results)

Writes those blocks to a file

Lower-level helpers, such as score_pairs, pairs_in_hit, straddling_pairs and to_wuss in firna.structures.pairs, are imported from their modules.

Examples#

Keep each region’s best family in a hits table, as a DataFrame:

from firna.api import HitTable

kept, dropped = HitTable.read('data/scans/rna3db.tbl').best_family_only()
df = kept.to_dataframe()

Hits from another source, such as a filtered DataFrame, work the same way:

from firna.api import Hit, HitTable

hits = [Hit(row.family, row.name, row.seq_from, row.seq_to, row.score, row.e_value)
        for row in df.itertuples()]
kept, _ = HitTable(hits).best_family_only()

Evaluate one family’s ArchiveII RNase P hits:

from firna.api import ReferenceCollection, HitTable, find_hits, evaluate_family, improved_family

references = ReferenceCollection.read_archiveii('data/archiveii/archiveii.parquet', subset='RNaseP')
hits = find_hits(HitTable.read('data/scans/archiveii-RNaseP.tbl'), references, best_family_only=True)
results = evaluate_family('RF00010', hits)
for result in results:
    print(result.name, {name: round(p.score.mcc, 3) for name, p in result.predictions.items()})
improved_family(results)

Evaluate RNA3DB hits on the strict benchmark set: exact missing residues, no gaps inside, at least one base pair, and hits covering 95% of their window:

from firna.api import ReferenceCollection, HitTable, read_missing_residues, find_hits, evaluate_family

references = ReferenceCollection.read_rna3db('data/annotations')
windows, dropped = references.scoring_windows(min_gap=1, min_pairs=1,
                                              missing=read_missing_residues('data/missing_residues.tsv'))
hits = find_hits(HitTable.read('data/scans/rna3db.tbl'), references,
                 best_family_only=True, windows=windows, min_coverage=0.95)
results = evaluate_family('RF00437', hits, fold=['rnafold'])

Read a finished run and list its improved families:

from firna.api import ConsensusEvaluation

run = ConsensusEvaluation.read('data/evaluations/2026-10-23_10-10-35_rna3db_secondary_best-family')
improved = run.improved_families()
