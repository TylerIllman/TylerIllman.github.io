firna.io.references.ReferenceCollection#

class firna.io.references.ReferenceCollection(references=())#

Bases: Mapping

Reference RNAs keyed by name, as read from a source or added by hand.

It can be used as a read-only dictionary of ReferenceRNAs, and it keeps the order they were added in.

match(hits)#

Pair hits with the RNAs they lie on, by sequence name.

The hits must come from a scan of these RNAs’ own sequences, as by firna scan-sequences, so that their names are the RNAs’ names. A hit repeated with the same family and coordinates is kept once, with its highest score.

Returns:

The ReferenceHits, in input order, and the sorted names of hits that match no RNA.

Parameters:

scoring_windows(min_gap=3, colon_only=False, missing=None, min_pairs=0)#

Choose each RNA’s scoring window, or the reason to leave it out.

Windows come from ReferenceRNA.scoring_window. missing gives each RNA’s missing residues, as from read_missing_residues, and an RNA it lacks is left out. Without it, RNA3DB chains’ missing bases are guessed from their annotations, and other RNAs are kept whole. An RNA with fewer than min_pairs base pairs in its window’s secondary structure is also left out.

Returns:

(start, end)} for the kept RNAs and {name: reason} for the others.

Return type:

{name
