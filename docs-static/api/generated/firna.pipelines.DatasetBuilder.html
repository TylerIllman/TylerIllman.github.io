firna.pipelines.DatasetBuilder#

class firna.pipelines.DatasetBuilder(data_dir=None, *, dataset_config=None, report=None, interface='python')#

Bases: Pipeline

The steps that build the family-informed dataset, so that related RNAs never straddle the split.

Run them in this order: seed_scan, link_families, find_components, split_components and build. They scan the seed sequences against Rfam, link the families that hit each other, join them into components, give every component to a split for every stage at once, and write the parquet files. make_assignment runs link_families, find_components and split_components in one call.

make_config writes the settings, and config reads them. rows and summary read what build wrote, and links, components, assignment, family and family_graph show the graph it was split by. download_data gets the Rfam files, the seed FASTA that seed_scan reads (include=['seed-fasta']) or the finished scan tables (include=['scans']). make_seed_fasta is the internal step that writes that FASTA on its own, and scan_sequences is the scan for any other input, such as reference structures.

Parameters:

  • data_dir – The data folder, or None for the default one (FIRNA_DATA, else ./data).

  • dataset_config – The config of a dataset kept somewhere else, whose assignment, manifest and rows are written beside it (default: data/dataset/dataset-config.json).

  • report – Called with each progress message. By default it logs to the firna logger.

  • interface (str) – ‘python’, or ‘cli’ for the command line, which decides how hints are written.

download_data(*, families=None, include=None, scans_url=None, rfam_version='CURRENT', overwrite=False, workers=4)#

Download the core Rfam files and selected families’ alignments.

include chooses core, seed, full or fasta files, or scans, the finished scan tables of the Rfam seed sequences, RNA3DB and ArchiveII, which take hours to make. Existing files are kept unless overwrite is true.

Parameters:

  • families (list[str] | None) – accessions (RF00030 or 30), all, 30-3000, 30- (onward) or -30 (up to)

  • include (list[str] | None) – what to download, any of core, seed, full, fasta, scans (the finished scan tables) and seed-fasta (every Rfam seed sequence in one FASTA file, made from Rfam.seed) (default: core, or core seed full with –families)

  • scans_url (str | None) – where the finished scan tables are, for scans: a folder that holds them, or an address with {name} for the file name (default: the published location)

  • rfam_version (str) – release (default: CURRENT)

  • overwrite (bool) – replace existing files

  • workers (int) – concurrent transfers (default: 4)

Return type:

None

scan_sequences(*, fasta=None, reference_structures=None, subset=None, mode='default', chunk=None, out=None, cm=None, cpu=None, overwrite=False, dry_run=False)#

Scan sequences against the Rfam models with cmscan.

Scans a FASTA file, or reference structures such as RNA3DB or ArchiveII. A large FASTA file can be split with chunk and scanned as many short jobs.

Parameters:

  • fasta (Path | None) – a FASTA file of sequences to scan, used as it is

  • reference_structures (Path | None) – sequences with known structures: an RNA3DB annotation folder, ArchiveII’s parquet file or a reference table (default: data/annotations)

  • subset (list[str] | None) – scan only RNAs with these family labels, for sources with a family column, such as RNaseP in ArchiveII

  • mode (str) – how many filters cmscan uses: default is Infernal’s usual filters, rfam is the faster filters Rfam itself uses, and max turns the filters off

  • chunk (str | None) – with –fasta, scan only share INDEX of COUNT equal shares of the sequences, such as 7/200, and write a table named for the chunk

  • out (Path | None) – hits table to write (default: data/scans/<source>.tbl, and with –fasta data/scans/<FASTA name>-<mode>.tbl)

  • cm (Path | None) – pressed Rfam model library (default: data/rfam/Rfam.cm)

  • cpu (int | None) – cmscan threads (default: the allocated CPUs under Slurm, otherwise all)

  • overwrite (bool) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path

make_config(sources, ratios=None, *, splits=None, filters=None, member_evalue=None, overwrite=False)#

Write the config file from a list of sources, as firna dataset make-config does, and return it.

Each source is written STAGE:NAME=PATH[,scan=PATH], such as finetune:rna3db=data/annotations,scan=data/scans/rna3db.tbl, or is a Source. A run folder such as data/structures/<run> stands for its tables, and a folder of runs for its newest run. The stages are the stages the sources name. ratios is {stage: ‘A:B:C’}, one share for each split, summing to 100, and splits names the splits (default: train, valid and test). The config is written whole, so it is the only place the sources are listed, and an existing one is refused unless overwrite is true.

Raises:

  • FileExistsError – If the config exists and overwrite is false.

  • ValueError – If a source, ratio or filter is not valid, or the config is not valid.

Parameters:

  • ratios (dict | None)

  • filters (dict | None)

  • member_evalue (float | None)

  • overwrite (bool)

Return type:

DatasetConfig

link_families(*, scans=None, criterion='evalue', link_evalue=None, cm=None, out=None, overwrite=False, dry_run=False)#

Turn a scan of seed sequences into links between Rfam families.

A seed sequence of family A that hits family B’s model is a link from A to B when it meets the criterion: an E-value of at most link_evalue (the default is every hit cmscan reports), or a bit score of at least B’s GA threshold. Each link keeps its evidence, so later steps choose how strict to be without scanning again.

Parameters:

  • scans (list[Path] | None) – one or more cmscan tables of seed sequences named family|name, such as every chunk of a scan; a quoted pattern like ‘data/scans/seeds-rfam.chunk-*.tbl’ is expanded by this command (default: data/scans/seeds-rfam.tbl)

  • criterion (str) – which hits count as links: evalue for an E-value at most –link-evalue, or ga for a bit score at least the target family’s GA threshold (default: evalue)

  • link_evalue (float | None) – with –criterion evalue, the largest E-value that counts; the default keeps every hit cmscan reports, so that firna dataset find-components can choose its own limit (default: 10)

  • cm (Path | None) – Rfam.cm, for the GA thresholds (default: data/rfam/Rfam.cm)

  • out (Path | None) – links table to write (default: data/graph/family_links.tsv)

  • overwrite (bool | str) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path

find_components(*, links=None, rfam_seed=None, min_fraction=0.2, min_sequences=None, link_evalue=None, no_clans=False, out=None, overwrite=False, dry_run=False)#

Join related families into components, which stay together in a split.

A link joins two families when at least the share min_fraction of the source family’s seed sequences hit the target, or, given min_sequences, when at least that many do, and a clan joins all its families. A family with no link is a component of its own.

Parameters:

  • links (Path | None) – links table from firna dataset link-families (default: data/graph/family_links.tsv)

  • rfam_seed (Path | None) – Rfam.seed, for the list of families and their clans (default: data/rfam/Rfam.seed)

  • min_fraction (float) – the share of the source family’s seed sequences that must hit the target for a link to join two families, above 0 and at most 1 (default: 0.2)

  • min_sequences (int | None) – join two families when at least this many of the source family’s seed sequences hit the target, however large the family is, instead of a share of them; it replaces –min-fraction

  • link_evalue (float | None) – count only sequences with an E-value of at most this, which cannot be looser than the links were made with (default: 0.01, at most 10)

  • no_clans (bool) – do not join the families of an Rfam clan (default: every family of a clan is joined)

  • out (Path | None) – components table to write (default: data/graph/components.tsv)

  • overwrite (bool | str) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path

split_components(*, dataset_config=None, components=None, time_limit=60, seed=0, out=None, overwrite=False, dry_run=False)#

Divide the components between the splits, for every stage together, and write the assignment.

A component goes on one side as a whole, so related sequences are never separated, and its one label applies to every stage. It is solved as an integer linear program with a time limit. Ratios are targets, one share for each split. The assignment has a row for every unit with its name, component and split, and the number of rows each source has in it.

Parameters:

  • dataset_config (Path | None) – the dataset config, its stages, sources, ratios and filters (default: data/dataset/dataset-config.json); when it is given, the assignment, manifest and rows are written beside it

  • components (Path | None) – components table from firna dataset find-components (default: data/graph/components.tsv)

  • time_limit (float) – how long the solver may improve the split (default: 60)

  • seed (int) – changes which of several equally good splits is chosen (default: 0)

  • out (Path | None) – assignment table to write (default: data/dataset/assignment.tsv)

  • overwrite (bool | str) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path

make_assignment(*, dataset_config=None, scans=None, criterion='evalue', link_evalue=None, min_fraction=0.2, min_sequences=None, no_clans=False, cm=None, rfam_seed=None, time_limit=60, seed=0, out=None, overwrite=False, dry_run=False)#

Make the assignment of a dataset from a scan of the Rfam seed sequences, in one command.

Links the families whose seed sequences hit each other, joins them into components by the rule given, and gives every component one of the splits of the dataset config, which is the table that firna dataset build reads. It is the command-line counterpart of the website’s builder, with the same settings, and it runs the steps link_families, find_components and split_components, so a step that has finished is kept. The links keep every hit up to an E-value of 10, so changing –link-evalue, –min-fraction, –min-sequences or –no-clans only joins the components again.

Parameters:

  • dataset_config (Path | None) – the dataset config, its stages, sources, ratios and filters (default: data/dataset/dataset-config.json); when it is given, the assignment, manifest and rows are written beside it

  • scans (list[Path] | None) – one or more cmscan tables of the Rfam seed sequences named family|name, such as every chunk of a scan; a quoted pattern like ‘data/scans/seeds-rfam.chunk-*.tbl’ is expanded by this command (default: data/scans/seeds-rfam.tbl)

  • criterion (str) – which hits link two families: evalue for an E-value of at most –link-evalue, or ga for a bit score at least the target family’s gathering threshold (default: evalue)

  • link_evalue (float | None) – with –criterion evalue, the largest E-value of a seed hit that counts, at most 10 (default: 0.01)

  • min_fraction (float) – the share of the source family’s seed sequences that must hit the target for a link to join two families, above 0 and at most 1 (default: 0.2)

  • min_sequences (int | None) – join two families when at least this many of the source family’s seed sequences hit the target, however large the family is, instead of a share of them

  • no_clans (bool) – do not join the families of an Rfam clan (default: every family of a clan is joined)

  • cm (Path | None) – Rfam.cm, for the gathering thresholds (default: data/rfam/Rfam.cm)

  • rfam_seed (Path | None) – Rfam.seed, for the list of families and their clans (default: data/rfam/Rfam.seed)

  • time_limit (float) – how long the solver may improve the split (default: 60)

  • seed (int) – changes which of several equally good splits is chosen (default: 0)

  • out (Path | None) – assignment table to write (default: data/dataset/assignment.tsv)

  • overwrite (bool) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path

build(*, dataset_config=None, assignment=None, out=None, overwrite=False, dry_run=False)#

Write the dataset as parquet files, by stage and split.

The assignment says which split each unit goes to, and is checked against the dataset config first. Rows that pass the filters are written once per family, then collected into one file per stage and split, such as pretrain_train.parquet. The manifest records the counts.

Parameters:

  • dataset_config (Path | None) – the dataset config, its stages, sources, ratios and filters (default: data/dataset/dataset-config.json); when it is given, the assignment, manifest and rows are written beside it

  • assignment (Path | None) – assignment table from firna dataset split-components (default: data/dataset/assignment.tsv), which may also come from the website; its source columns must match the dataset config

  • out (Path | None) – manifest to write (default: data/dataset/manifest.json)

  • overwrite (bool) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path
