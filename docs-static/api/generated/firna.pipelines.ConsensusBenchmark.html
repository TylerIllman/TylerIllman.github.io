firna.pipelines.ConsensusBenchmark#

class firna.pipelines.ConsensusBenchmark(data_dir=None, *, report=None, interface='python')#

Bases: Pipeline

The steps that score consensus structures against known ones.

Run them in this order: find_missing_residues, make_set and evaluate_consensus. They find the unresolved residues of the reference chains, choose the reference RNAs and their scoring windows, and score every structure with F1 and MCC. compare reads a finished evaluation and lays the structures of chosen hits onto each chain, for inspection by eye.

Parameters:

  • data_dir – The data folder, or None for the default one (FIRNA_DATA, else ./data).

  • report – Called with each progress message. By default it logs to the firna logger.

  • interface (str) – ‘python’, or ‘cli’ for the command line, which decides how hints are written.

find_missing_residues(*, reference_structures=None, mmcif_dir=None, out=None, not_found=None, overwrite=False, dry_run=False)#

Find each RNA3DB chain’s residues that have no atoms, from the PDB’s mmCIF files.

A residue is missing when its chain lists it but no atom of the 3D structure belongs to it. The table feeds make-set.

Parameters:

  • reference_structures (Path | None) – RNA3DB annotation folder naming the chains (default: data/annotations)

  • mmcif_dir (Path | None) – folder of <entry>.cif.gz files (default: data/mmcif)

  • out (Path | None) – table to write (default: data/missing_residues.tsv)

  • not_found (Path | None) – also write the chains that could not be found, with the reason for each

  • overwrite (bool) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

make_set(*, reference_structures=None, subset=None, out=None, dropped=None, missing_residues=None, min_gap=3, min_pairs=None, colon_only=False, overwrite=False, dry_run=False)#

Choose the reference RNAs to evaluate and where to score each one.

Leaves out RNAs with a long run of missing bases or too few base pairs, and gives each kept RNA a scoring window.

Parameters:

  • reference_structures (Path | None) – sequences with known structures: an RNA3DB annotation folder, ArchiveII’s parquet file or a reference table (default: data/annotations)

  • subset (list[str] | None) – use only reference RNAs with these family labels, for sources with a family column

  • out (Path | None) – benchmark set table to write (default: data/benchmark_set.tsv)

  • dropped (Path | None) – also write the RNAs left out, with the reason for each

  • missing_residues (Path | None) – table from firna benchmark find-missing-residues giving each chain’s residues without atoms; chains it lacks are left out

  • min_gap (int) – leave out RNAs with this many missing bases in a row inside the scoring window (default: 3)

  • min_pairs (int | None) – leave out RNAs with fewer base pairs than this in the scoring window

  • colon_only (bool) – without –missing-residues, count every ‘:’ in the secondary structure as missing, even if another RNAview layer records an interaction for that base

  • overwrite (bool) – Replace an output that was made from different inputs or settings.

  • dry_run (bool) – Print what would be read and written, and write nothing.

Return type:

Path

evaluate_consensus(*, families=None, hits_table=None, benchmark_set=None, min_coverage=None, workers=1, list_families=False, resume=False, verbose=False, out=None, structure_dir=None, include_structures=None, cm=None, rfam_seed=None, best_family_only=False, reference_layer='secondary', fold=None)#

Score consensus structures against known RNA structures.

For each family with significant hits, aligns the hit sequences to the CM and scores every structure (cm, rfam_seed and each structure of the structure library) against the known pairs with F1 and MCC. Each run writes to its own folder.

Parameters:

  • families (list[str] | None) – accessions, all, 30-3000, 30-, or -30; chosen from families with significant hits in the table

  • hits_table (Path | None) – cmscan –tblout table of the reference sequences, as written by firna scan-sequences

  • benchmark_set (Path | None) – table from firna benchmark make-set, which names the reference structures and the reference RNAs to evaluate, each scored within its window (default: data/benchmark_set.tsv)

  • min_coverage (float | None) – evaluate only hits covering at least this fraction of their window, such as 0.95

  • workers (int) – parallel family processes (default: 1)

  • list_families (bool) – print selected family accessions, one per line, without evaluating

  • resume (bool) – continue –out, or the latest run, skipping families already evaluated

  • verbose (bool) – log each family as it starts and print full tracebacks for failures

  • out (Path | None) – run folder (default: a new folder named after the start time, in data/evaluations)

  • structure_dir (str | None) – consensus structures laid out as <folder>/<family>/<structure>/<file>.sto, each named in the results after its structure folder; may contain {family} (default: the newest run in data/cacofold/, named cacofold_<structure>)

  • include_structures (list[str] | None) – structures to use, such as seed_full (default: all the family has)

  • cm (Path | None) – Rfam.cm library (default: data/rfam/Rfam.cm)

  • rfam_seed (Path | None) – Rfam.seed, for the rfam_seed structure (default: data/rfam/Rfam.seed)

  • best_family_only (bool) – where several families hit the same region of a chain, keep only the hit with the lowest E-value

  • reference_layer (str) – structure layer of the reference RNAs used as the known structure, such as secondary or, for RNA3DB, cWW (default: secondary)

  • fold (list[str] | None) – also fold each hit’s sequence on its own with these methods and score the result: rnafold

Return type:

None

compare(*, families=None, families_file=None, hits=None, only_improved=False, min_gain=0.0, baseline='rfam_seed', evaluation_run=None, out=None, list_families=False)#

Show every structure for each hit of chosen families, laid onto its whole chain, with scores.

Writes Stockholm files with the chain, each structure and its score, from the hits, structures and scores that an evaluate run saved.

Parameters:

  • families (list[str] | None) – accessions, all, ranges such as 30-3000, 30- or -30

  • families_file (Path | None) – table with a family column, or one accession per line

  • hits (Path | None) – hits to compare: a table with family and hit columns, or lines such as RF04326 7jju_A/2-51, RF04326, or 7jju_A

  • only_improved (bool) – keep only families where a library structure’s mean MCC over the family’s hits beats –baseline, with all their hits

  • min_gain (float) – with –only-improved, the margin in mean MCC a library structure must beat the baseline by (default: 0)

  • baseline (str) – with –only-improved, the structure to beat, by its name in the comparison tables (default: rfam_seed)

  • evaluation_run (Path | None) – the firna benchmark evaluate-consensus run folder whose hits, structures and scores are shown (default: the newest run in data/evaluations/)

  • out (Path | None) – write every hit to this one file (default: one file per family, <run>/<family>/<family>_eval_structures.sto in the evaluation run)

  • list_families (bool) – print the selected families and exit

Return type:

None
