firna.io.structure_tables.StructureTable#

class firna.io.structure_tables.StructureTable(rows=())#

Bases: object

Structures held in memory, as StructureRows, to add to, remove from and write out as tables.

Rows keep the order they were added in. A row with no family is listed under UNMATCHED, by families, family and remove, and is written to unmatched.structures.tsv.

For example:

structures = StructureTable.read(‘rfam_structures.zip’) structures.add(‘seq1’, ‘GGGAAACCC’, ‘(((…)))’, family=’RF00005’) structures.remove(family=’RF00001’) structures.write(‘out_folder’)

write(out, *, compress=False)#

Write one <family>.structures.tsv for each family, and return the paths written.

The tables have the columns name, sequence and structure, as firna structures extract writes them, so the result is a source for firna dataset make-config. out ending in .zip gives one zip file that holds the tables, and any other out is a folder that gets them directly. compress gzips each table and adds .gz to its name. The output is written under a temporary name and renamed when complete.

Return type:

list[Path]
