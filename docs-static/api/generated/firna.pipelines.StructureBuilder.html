firna.pipelines.StructureBuilder#

class firna.pipelines.StructureBuilder(data_dir=None, *, report=None, interface='python')#

Bases: Pipeline

The steps that get the structures of Rfam families.

Run them in this order: download_data, build_alignments, run_cacofold and extract. They fetch the Rfam files, build the seed, full and seed+full MSAs, fold each with CaCoFold, and extract every sequence’s structure from the consensus of its MSA. predict takes sequences of its own and gives them the structures of the families they hit.

Parameters:

  • data_dir – The data folder, or None for the default one (FIRNA_DATA, else ./data).

  • report – Called with each progress message. By default it logs to the firna logger.

  • interface (str) – ‘python’, or ‘cli’ for the command line, which decides how hints are written.

download_data(*, families=None, include=None, scans_url=None, rfam_version='CURRENT', overwrite=False, workers=4)#

Download the core Rfam files and selected families’ alignments.

include chooses core, seed, full or fasta files, or scans, the finished scan tables of the Rfam seed sequences, RNA3DB and ArchiveII, which take hours to make. Existing files are kept unless overwrite is true.

Parameters:

  • families (list[str] | None) – accessions (RF00030 or 30), all, 30-3000, 30- (onward) or -30 (up to)

  • include (list[str] | None) – what to download, any of core, seed, full, fasta, scans (the finished scan tables) and seed-fasta (every Rfam seed sequence in one FASTA file, made from Rfam.seed) (default: core, or core seed full with –families)

  • scans_url (str | None) – where the finished scan tables are, for scans: a folder that holds them, or an address with {name} for the file name (default: the published location)

  • rfam_version (str) – release (default: CURRENT)

  • overwrite (bool) – replace existing files

  • workers (int) – concurrent transfers (default: 4)

Return type:

None

build_alignments(*, families=None, workers=1, list_families=False, resume=None, verbose=False, run=None, full_alignment=None, out=None, evalue=0.01, max_sequences=None, evalue_match='id', include=['seed', 'full', 'seed_full'])#

Build the seed, full and seed+full MSAs of selected families.

Needs the files from download. Each family is built in a temporary folder and moved into place when complete, and families run in parallel.

Parameters:

  • families (list[str] | None) – accessions, all, 30-3000, 30-, or -30; ranges use local full alignments

  • workers (int) – parallel family processes (default: 1)

  • list_families (bool) – print selected local family accessions, one per line, without building

  • resume (str | None) – continue a run, the newest one without RUN, or RUN given as a name in data/alignments/ or a path: skip complete matching alignments and reject incomplete ones

  • verbose (bool) – log each family as it starts and print full tracebacks for failures

  • run (str | None) – name of the run folder to write into, made if new (default: the start time)

  • full_alignment (Path | None) – override the input full Stockholm file

  • out (Path | None) – exact directory for one family; parent directory for multiple families (default: data/alignments/<run>/<family>)

  • evalue (float) – for filtered: keep full rows with an E-value below this (default: 0.01)

  • max_sequences (int | None) – for filtered: keep at most N rows, drawn at random with a fixed seed from those that pass –evalue (default: no limit)

  • evalue_match (str) – for filtered: match full_region by exact ID, or also by identical sequence

  • include (list[str] | None) – MSAs to build; default: seed full seed_full. Add filtered explicitly.

Return type:

None

run_cacofold(*, families=None, workers=1, list_families=False, resume=None, verbose=False, run=None, alignments_run=None, alignment_dir=None, rscape=None, figures=False, include_cm=False, cm=None)#

Run CaCoFold on the alignments of selected families.

Needs the alignments from build-alignments. The layers of every fold are collected in structures.json. Families run in parallel, and finished folds are reused.

Parameters:

  • families (list[str] | None) – accessions, all, 30-3000, 30-, or -30; ranges use families with alignments

  • workers (int) – parallel family processes (default: 1)

  • list_families (bool) – print selected family accessions, one per line, without folding

  • resume (str | None) – continue a run, the newest one without RUN, or RUN given as a name in data/cacofold/ or a path: skip families that already have structures.json

  • verbose (bool) – log each family as it starts and print full tracebacks for failures

  • run (str | None) – name of the run folder to write into, made if new (default: the start time)

  • alignments_run (str | None) – name of the build-alignments run to fold (default: the newest run in data/alignments/)

  • alignment_dir (Path | None) – MSA directory for a single family (default: data/alignments/<alignments run>/FAMILY)

  • rscape (str | None) – R-scape executable; defaults to R-scape on PATH

  • figures (bool) – also render R-scape figures

  • include_cm (bool) – also put the family CM consensus structure in structures.json

  • cm (Path | None) – family CM or Rfam.cm; defaults to family CM if present, else data/rfam/Rfam.cm

Return type:

None

extract(*, families=None, msa=None, merge_layers=False, combine=None, zip=None, stats=None, workers=1, list_families=False, resume=None, verbose=False, out=None)#

Extract each sequence’s secondary structure from the consensus of its MSA.

Writes one table of name, sequence and structure per MSA, and optionally one combined table, a zip file of the tables and statistics. Runs can be resumed.

Parameters:

  • families (list[str] | None) – accessions, all, 30-3000, 30-, or -30; chosen from families whose –msa pattern matches a file

  • msa (str | None) – MSA path; {family} stands for each accession and * matches any name part (default: the newest run in data/cacofold/, data/cacofold/<run>/{family}/*/*.cacofold.sto)

  • merge_layers (bool) – merge a CaCoFold fold’s extra SS_cons_* layers into one structure, resolving clashes by covariation E-value (default: SS_cons only)

  • combine (Path | None) – also write every table into one table with a family column; .gz compresses it

  • zip (Path | None) – also write every table into one zip file, which firna dataset make-config reads as a source

  • stats (Path | None) – also write summary statistics of every table to FOLDER and print them beside bpRNA-1m

  • workers (int) – MSAs processed concurrently (default: 1)

  • list_families (bool) – print the selected families and exit

  • resume (str | None) – continue a run, the newest one without RUN, or RUN given as a name in data/extractions/ or a path: skip MSAs already extracted

  • verbose (bool) – log each MSA as it starts and print full tracebacks for failures

  • out (Path | None) – run folder (default: a new folder named after the start time in data/extractions/); its name also names the folder of tables in data/structures/

Return type:

None

predict(query=None, *, name='query', structure_dir=None, include_structures=None, best_family_only=False, workers=1, resume=False, verbose=False, out=None, cm=None)#

Predict the secondary structure of new RNA sequences from Rfam and CaCoFold.

Scans the sequences against Rfam, aligns each hit to its family CM and transfers the family’s structures onto it. Each run writes to its own folder.

Parameters:

  • query (str | None) – one RNA or DNA sequence, or a FASTA file of sequences

  • name (str) – name for a sequence given on the command line (default: query)

  • structure_dir (str | None) – folder laid out as <folder>/<family>/<structure>/<file>.sto; may contain {family} (default: the newest run in data/cacofold/)

  • include_structures (list[str] | None) – structures to use, such as seed_full (default: all the family has)

  • best_family_only (bool) – where hits of several families on one sequence overlap, keep only the hit with the lowest E-value (default: keep every significant hit)

  • workers (int) – parallel family processes and cmscan threads (default: 1)

  • resume (bool) – continue –out, or the latest run, skipping families already predicted

  • verbose (bool) – log each family as it starts and print full tracebacks for failures

  • out (Path | None) – run folder (default: a new folder named after the start time, in data/predictions)

  • cm (Path | None) – pressed Rfam.cm library (default: data/rfam/Rfam.cm)

Return type:

None
