firna.io.hits.HitTable#

class firna.io.hits.HitTable(hits=())#

Bases: object

Family hits, kept in the order they were added.

It usually holds the Hits of a cmscan table, as read by read. It can hold anything with the fields of HitLike, so that HitTable(reference_hits).best_family_only() works on ReferenceHits.

classmethod read(path, family=None, significant_only=True)#

Read a cmscan –tblout table (format 1), in table order.

Parameters:

  • path (str | Path) – The table, such as one written by firna scan-sequences.

  • family (str | None) – Keep only this family’s hits.

  • significant_only (bool) – Keep only significant (!) hits.

Raises:

  • FileNotFoundError – If the table does not exist.

  • ValueError – If a line is malformed or names an invalid accession.

Return each sequence’s family, from its best-ranked hit at or below max_evalue.

best_family_only(min_overlap=0.5)#

Keep only the best-ranked family wherever hits on one sequence overlap.

Two hits of different families on the same sequence compete when they overlap by more than min_overlap of the shorter hit, on either strand.

Returns:

The kept hits and the dropped hits, each in table order.
