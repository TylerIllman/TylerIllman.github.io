Conda environment#

Create the environment once, from the repository root:

conda env create -f environment.yml
conda activate rfam

To apply later changes to environment.yml:

conda env update -n rfam -f environment.yml

The environment installs this repository in editable mode, so changes under src/firna/ take effect without reinstalling.

The firna command#

Installing the package provides the firna command, with one subcommand per pipeline stage:

firna --help
firna structures predict --help

python -m firna is equivalent and works without the command being installed. If firna is not found after updating the repository, reinstall the package once to register it:

python -m pip install -e ".[dev]"

The data folder#

Every command works on files in one data folder. firna init-data-folder creates it and firna init-data-folder --download also fetches the shared Rfam files and presses Rfam.cm, so that the commands can then be run with their defaults:

firna init-data-folder --download
firna show-layout

The folder is --data-dir, else the FIRNA_DATA environment variable, else ./data. See firna show-layout.

R-scape#

firna structures run-cacofold runs CaCoFold through the R-scape executable on PATH. A different executable can be selected per run with firna structures run-cacofold --rscape PATH.

Preparing Rfam.cm#

firna scan-sequences and firna structures predict search with cmscan, which requires a pressed model library. firna init-data-folder --download presses it. To press it by hand, run cmpress once after Rfam.cm is downloaded:

cmpress data/rfam/Rfam.cm

cmpress writes four index files beside the library (.i1m, .i1i, .i1f, .i1p). After downloading a new Rfam.cm, delete these files and press again.

Verifying the installation#

pytest

Data directory#

All commands read from and write to data/, or the directory given with --data-dir:

data/
├── rfam/                 Rfam.seed, Rfam.cm, Rfam.full_region, Rfam.pdb
├── rfam/families/<family>/ full and seed alignments from Rfam (`firna download-data`)
├── alignments/<run>/       MSAs of each family (`firna structures build-alignments`)
├── cacofold/<run>/         CaCoFold output of each family (`firna structures run-cacofold`)
├── structures/<run>/       structure tables of each family (`firna structures extract`)
├── extractions/<run>/      records of each extraction (`firna structures extract`)
├── scans/                cmscan tables and the FASTA files they were made from (`firna scan-sequences`)
├── graph/                links between families and their components
├── dataset/              the dataset config, the assignment and the parquet files
├── annotations/          RNA3DB annotation JSON files
├── evaluations/          runs of `firna benchmark evaluate-consensus`
├── comparisons/          runs of `firna benchmark compare`
└── predictions/          runs of `firna structures predict`
