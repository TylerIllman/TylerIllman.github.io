Tasks#

This page lists the common tasks and how to complete each one. Each code block is labelled CLI or Python. Where a task has both, they run the same code with the same defaults and write the same files. The examples assume that the data folder is data/. Each command is described in full in the command-line reference, and each class in the Python API reference.

A run is one folder of results. The commands that work through many families, such as run-cacofold and evaluate-consensus, write a new folder each time they are started, so earlier results are kept. Concepts describes runs.

Set up the data folder#

Create the folders, download the shared Rfam files and prepare Rfam.cm for searching. This is done once.

Reference: firna init-data-folder, init.

firna init-data-folder --download

from firna.setup import init

init('data', download=True)

Check a step before running it#

--dry-run prints what a stage would read, write and run, and whether an existing output would be kept, replaced or refused. It writes nothing and fails if an input is missing, so it is a quick check before a long job.

Reference: firna scan-sequences, Stage contract.

firna scan-sequences --fasta data/scans/seeds.fa --mode rfam --dry-run

from firna import DatasetBuilder

builder = DatasetBuilder('data')
builder.scan_sequences(fasta='data/scans/seeds.fa', mode='rfam', dry_run=True)

The output of both is the same:

scan-sequences (dry run)
  read   data/scans/seeds.fa  found
  read   data/rfam/Rfam.cm  found
  read   data/rfam/Rfam.cm.i1m  found
  ...
  write  data/scans/seeds-rfam.tbl  does not exist, would be created
  run    cmscan --noali --rfam data/rfam/Rfam.cm data/scans/seeds.fa
Nothing was written.

Fold a family’s alignments with CaCoFold#

Download a family’s alignments, build the seed, full and seed+full MSAs, fold each with CaCoFold, and extract every sequence’s structure.

Reference: firna download-data, firna structures build-alignments, firna structures run-cacofold, firna structures extract, StructureBuilder.

firna download-data --families RF00005
firna structures build-alignments --families RF00005
firna structures run-cacofold --families RF00005
firna structures extract --families RF00005

from firna import StructureBuilder

structures = StructureBuilder('data')
structures.download_data(families=['RF00005'])
structures.build_alignments(families=['RF00005'])
structures.run_cacofold(families=['RF00005'])
structures.extract(families=['RF00005'])

Limit an alignment by E-value or size#

The seed, full and seed_full MSAs have no E-value filter or size limit. The filtered MSA holds the full rows below --evalue, and at most --max-sequences of them, drawn at random with a fixed seed.

Reference: firna structures build-alignments, StructureBuilder.

firna structures build-alignments --families RF00017 --include seed filtered --evalue 1e-5 --max-sequences 5000

from firna import StructureBuilder

StructureBuilder('data').build_alignments(families=['RF00017'], include=['seed', 'filtered'],
                                    evalue=1e-5, max_sequences=5000)

Get a structure for every sequence of Rfam’s alignments#

Project each family’s consensus onto its sequences, and write the tables as a zip file that a dataset can use as a source.

Reference: firna download-data, firna structures extract, StructureBuilder.

firna download-data --families all --include seed full
firna structures extract --families all --msa 'data/rfam/families/{family}/{family}.sto' --resume --zip data/rfam_structures.zip

from firna import StructureBuilder

structures = StructureBuilder('data')
structures.download_data(families=['all'], include=['seed', 'full'])
structures.extract(families=['all'], msa='data/rfam/families/{family}/{family}.sto', resume=True,
                   zip='data/rfam_structures.zip')

Predict the structures of new sequences#

Scan the sequences against Rfam, align each hit to its family’s model and transfer the family’s structures onto it.

Reference: firna structures predict, StructureBuilder.

firna structures predict queries.fa --best-family-only --workers 8 --out results/my_queries

from firna import StructureBuilder

StructureBuilder('data').predict('queries.fa', best_family_only=True, workers=8, out='results/my_queries')

Find the Rfam family of each sequence#

Scan the sequences, then keep each sequence’s best family. The best family has the lowest E-value, then the highest bit score, then the lowest accession.

Reference: firna scan-sequences, HitTable.

from firna import DatasetBuilder
from firna.api import HitTable

table = DatasetBuilder('data').scan_sequences(fasta='queries.fa', out='data/scans/queries.tbl')
hits = HitTable.read(table)
families = hits.best_families(max_evalue=0.01)                # {sequence name: family}
kept, dropped = hits.best_family_only()                       # the best family of each region
kept.to_dataframe().to_csv('data/queries_hits.csv', index=False)

Use your own reference structures#

The commands read three sources: RNA3DB annotations, ArchiveII’s parquet file and a reference table. Any other data is set up in Python and written as a reference table, which every command then reads with --reference-structures. The columns of the table are given in Reference structures.

Reference: firna scan-sequences, firna benchmark make-set, ReferenceCollection.

import pandas as pd
from firna.api import ReferenceCollection

references = ReferenceCollection()
for row in pd.read_csv('my_structures.csv').itertuples():
    references.add(row.rna, row.seq, row.dot_bracket)
references.write('data/my_references.tsv')

firna scan-sequences --reference-structures data/my_references.tsv
firna benchmark make-set --reference-structures data/my_references.tsv --out data/benchmark_set_mine.tsv

Write the families of a dataset as a folder or a zip file#

Give each sequence the family it hits, and write one <family>.structures.tsv for each family that has at least one sequence. Sequences with no family go to unmatched.structures.tsv. A dataset does not need this, because firna dataset make-config reads a reference source and its scan directly.

Reference: firna scan-sequences, HitTable, ReferenceCollection, StructureTable.

from firna import DatasetBuilder
from firna.api import HitTable, ReferenceCollection
from firna.io.structure_tables import StructureTable

scan = DatasetBuilder('data').scan_sequences(reference_structures='data/archiveii/archiveii.parquet')
references = ReferenceCollection.read_archiveii('data/archiveii/archiveii.parquet')
families = HitTable.read(scan, significant_only=False).best_families(max_evalue=0.01)

table = StructureTable()
for name, rna in references.items():
    table.add(name, rna.sequence, rna.structure(), family=families.get(name))
table.write('data/archiveii_families.zip')       # or a folder, without the .zip

Build a dataset whose splits never share a family#

List the sources of each stage, make the assignment from the scan of the seed sequences, and write the parquet files. firna download-data --include scans fetches the finished scan in place of the first two lines. --mode rfam gives cmscan the strict filters of firna scan-sequences, which makes the scan of every seed sequence affordable.

Reference: firna download-data, firna scan-sequences, firna dataset make-config, firna dataset make-assignment, firna dataset build, DatasetBuilder.

firna download-data --include core seed-fasta
firna scan-sequences --fasta data/scans/seeds.fa --mode rfam
firna scan-sequences --reference-structures data/archiveii/archiveii.parquet
firna dataset make-config --source pretrain:rfam=data/rfam_structures.zip --source finetune:archiveii=data/archiveii/archiveii.parquet --ratios pretrain=90:5:5 --ratios finetune=70:15:15
firna dataset make-assignment
firna dataset build

from firna import DatasetBuilder

builder = DatasetBuilder('data')
builder.download_data(include=['core', 'seed-fasta'])
builder.seed_scan()
builder.scan_sequences(reference_structures='data/archiveii/archiveii.parquet')
builder.make_config(['pretrain:rfam=data/rfam_structures.zip',
                     'finetune:archiveii=data/archiveii/archiveii.parquet'],
                    ratios={'pretrain': '90:5:5', 'finetune': '70:15:15'})
builder.make_assignment()
builder.build()
builder.rows('pretrain', 'train')                # the rows of one split, as a DataFrame

Reference: DatasetBuilder.

from firna import DatasetBuilder

builder = DatasetBuilder('data')
builder.family('RF00005')                        # its component, split and links
builder.components()

Score consensus structures against known structures#

Score each family’s structures on its hits to the reference RNAs. The family’s CM structure and Rfam’s seed structure are always scored. The structures are those of the newest run of run-cacofold, or any consensus structures laid out as a structure library and given with --structure-dir.

Reference: firna scan-sequences, firna benchmark make-set, firna benchmark evaluate-consensus, HitTable, ReferenceCollection, evaluate_family, family_means, find_hits, ConsensusBenchmark.

firna scan-sequences --reference-structures data/archiveii/archiveii.parquet --subset RNaseP
firna benchmark make-set --reference-structures data/archiveii/archiveii.parquet --subset RNaseP --out data/benchmark_set_rnasep.tsv
firna benchmark evaluate-consensus --families RF00010 --hits-table data/scans/archiveii-RNaseP.tbl --benchmark-set data/benchmark_set_rnasep.tsv --best-family-only --fold rnafold
firna benchmark evaluate-consensus --families RF00010 --hits-table data/scans/archiveii-RNaseP.tbl --benchmark-set data/benchmark_set_rnasep.tsv --structure-dir my_structures --out results/my_structures

On objects in memory:

from firna.api import HitTable, ReferenceCollection, evaluate_family, family_means, find_hits

references = ReferenceCollection.read_archiveii('data/archiveii/archiveii.parquet', subset='RNaseP')
hits = find_hits(HitTable.read('data/scans/archiveii-RNaseP.tbl'), references, best_family_only=True)
results = evaluate_family('RF00010', hits, fold=['rnafold'])
family_means(results)

Writing the same files as the commands:

from firna import ConsensusBenchmark

benchmark = ConsensusBenchmark('data')
benchmark.make_set(reference_structures='data/archiveii/archiveii.parquet', subset=['RNaseP'],
                   out='data/benchmark_set_rnasep.tsv')
benchmark.evaluate_consensus(families=['RF00010'], hits_table='data/scans/archiveii-RNaseP.tbl',
                             benchmark_set='data/benchmark_set_rnasep.tsv', best_family_only=True, fold=['rnafold'])

Score only the resolved part of RNA3DB chains#

Read the missing residues from the mmCIF files and leave out chains with unresolved bases inside them.

Reference: firna benchmark find-missing-residues, firna benchmark make-set, firna benchmark evaluate-consensus, HitTable, ReferenceCollection, evaluate_family, find_hits, read_missing_residues.

firna benchmark find-missing-residues
firna benchmark make-set --missing-residues data/missing_residues.tsv --min-gap 1 --min-pairs 1 --out data/benchmark_set_strict.tsv
firna benchmark evaluate-consensus --families all --hits-table data/scans/rna3db.tbl --benchmark-set data/benchmark_set_strict.tsv --best-family-only --min-coverage 0.95 --workers 8

from firna.api import HitTable, ReferenceCollection, evaluate_family, find_hits, read_missing_residues

references = ReferenceCollection.read_rna3db('data/annotations')
windows, dropped = references.scoring_windows(min_gap=1, min_pairs=1,
                                              missing=read_missing_residues('data/missing_residues.tsv'))
hits = find_hits(HitTable.read('data/scans/rna3db.tbl'), references, best_family_only=True,
                 windows=windows, min_coverage=0.95)
results = evaluate_family('RF00437', hits)

Read the results of an evaluation run#

An evaluation run is the folder that one firna benchmark evaluate-consensus command writes. It is a new folder in data/evaluations/, named after the start time and the settings, such as 2026-10-06_14-32-05_rna3db_secondary, or the folder given with --out. It holds the comparison tables as CSV files, with one row for each family, and the result of each hit in a folder for each family.

The results of each hit are read as HitResults. compare writes every structure laid onto its chain as a Stockholm file, from the newest run or the one given with --evaluation-run.

Reference: firna benchmark compare, ConsensusEvaluation.

firna benchmark compare --families all --only-improved --min-gain 0.05 --out improved.sto

from firna.api import ConsensusEvaluation

run = ConsensusEvaluation.read('data/evaluations/my_run')
run['RF00010']                                   # the HitResults of one family
run.improved_families(min_gain=0.05, baseline='rfam_seed')

Change one setting without redoing earlier work#

Every stage records the inputs and options of its output, so a later stage can be run again with new settings while the expensive earlier ones are kept. For example, a benchmark set with a stricter rule reuses the table of missing residues. Giving it its own --out leaves the default data/benchmark_set.tsv as it was. Asking for different options into the same file is refused until --overwrite is added.

Reference: firna benchmark make-set, Stage contract.

firna benchmark make-set --missing-residues data/missing_residues.tsv --min-gap 1 --min-pairs 1 --out data/benchmark_set_strict.tsv

from firna import ConsensusBenchmark

benchmark = ConsensusBenchmark('data')
benchmark.make_set(missing_residues='data/missing_residues.tsv', min_gap=1, min_pairs=1,
                   out='data/benchmark_set_strict.tsv')
