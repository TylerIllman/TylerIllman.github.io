Command-line reference#

FIRNA is used through one command, firna, and its commands come in two kinds. The general commands set up the data folder and are used by every pipeline, so they are typed as they are, such as firna download-data. The three pipelines that FIRNA provides each have a name that comes first: firna dataset ... creates family-informed datasets, firna structures ... works with secondary structures, and firna benchmark ... scores structures against known ones. firna --help lists every command, firna dataset lists the commands of one pipeline, and firna <command> --help lists the options of one. Every command reads and writes files in the data folder, whose layout firna show-layout prints. The Python interface of each step is described in the Python API reference.

General commands#

firna init-data-folder --download is run once. It prepares the data folder that every other command reads and writes, and fetches the Rfam files that the pipelines start from.

Command

Description

Input

Output

firna init-data-folder

Creates the data folder and, with --download, fetches the shared Rfam files and prepares the model library for searching.

The Rfam FTP site, with --download.

The data folder and, with --download, the shared Rfam files.

firna show-layout

Lists every standard path of the data folder and whether it exists, to show what has been made and what is missing.

The data folder.

Standard output.

firna download-data

Downloads the Rfam files, the alignments of each family, the finished scan tables, and, as an option, one FASTA file of every Rfam seed sequence.

The Rfam FTP site.

Rfam files in data/rfam/, family files in data/rfam/families/, and scan tables and the seed FASTA in data/scans/.

firna scan-sequences

Searches sequences against every Rfam family model with cmscan. It scans the seed sequences to find related families, and it scans reference structures such as RNA3DB or ArchiveII so that each one gets an Rfam family. A large input can be split into chunks.

A FASTA file or reference structures, and Rfam.cm.

data/scans/<name>.tbl: the cmscan table of hits.

Dataset: family-informed splits#

These commands are the steps of the DatasetBuilder class, with which family-informed RNA structure datasets are created: related families never fall on different sides of the training, validation and test splits, so no family leaks between them.

make-config writes the config that lists the structures that make up the dataset, with the splits and their ratios. make-assignment finds which families resemble each other from the scan of the Rfam seed sequences, joins them into groups of related families with the settings given, and assigns each group to one split. build then writes the rows. Pretraining and fine-tuning sources share one split, so related RNAs are on the same side in both. The scan is made by scan-sequences, or downloaded with download-data --include scans. The three steps inside make-assignment, link-families, find-components and split-components, are also available as internal commands.

Command

Description

Input

Output

firna dataset make-config

Writes the dataset config from all of its sources at once, each given a stage and a name, for pretraining (such as the structures projected from Rfam) or for fine-tuning (such as RNA3DB or ArchiveII), with the split ratios and row filters.

Files of structures.

data/dataset/dataset-config.json: the sources of the dataset.

firna dataset make-assignment

Makes the assignment from the scan of the Rfam seed sequences in one command: links the families whose seed sequences hit each other, joins them into components by the rule given (an E-value, a share or a number of seed sequences, clans), and gives each component one of the splits with an integer linear program. The settings are written at the top of the table.

The scan of the seed sequences and the dataset config.

data/dataset/assignment.tsv: the split of every unit, with the rows each source has in it.

firna dataset build

Reads the sources, applies the row filters (length, base pairs, ambiguity), and writes the rows that remain as parquet files, one per family and then one per stage and split, such as pretrain_train.parquet. A manifest records the counts.

The assignment, sources and the dataset config.

data/dataset/: parquet files for each dataset stage and split.

Structures#

These commands work with secondary structures. run-cacofold folds a multiple sequence alignment with CaCoFold, extract gives every sequence of an alignment its own structure from the alignment’s consensus, and predict gives any sequences the structures of the families they hit. Run for every Rfam family, they produce the pretraining data: a secondary structure for every sequence, whose tables are the main pretraining source of the dataset. The alignments of the Rfam families are built by the internal command build-alignments.

Command

Description

Input

Output

firna structures run-cacofold

Predicts a consensus secondary structure for each alignment with CaCoFold, which uses the covariation in the alignment.

The MSAs.

data/cacofold/<run>/<family>/: CaCoFold structures.

firna structures extract

Projects the consensus structure of each family onto every sequence of its alignments, giving one structure per sequence. The run folder it writes is what make-config takes as the pretraining source.

CaCoFold alignments.

Tables of name, sequence and structure, one per MSA.

firna structures predict

Predicts structures for any sequences. It searches them against the family models with cmscan and gives each hit the structures of its family.

Sequences.

data/predictions/<run>/: structures predicted for each sequence.

Benchmark#

These commands are the steps of the ConsensusBenchmark class, in the order shown. They score structure predictions against known structures, so that the structures from Rfam can be compared with other predictors on RNA3DB or ArchiveII.

Command

Description

Input

Output

firna benchmark make-set

Chooses the reference RNAs to score and the window of each chain that is scored, leaving out missing ends. Saving the choice keeps every evaluation on the same benchmark set.

Reference structures.

data/benchmark_set.tsv: the reference RNAs and their scoring windows.

firna benchmark evaluate-consensus

Scores predicted structures against the reference structures with the F1 score and the Matthews correlation coefficient, for each family and each source of structures.

A scan table, reference structures and CaCoFold structures.

data/evaluations/<run>/: scores for each family.

Internal commands#

These commands prepare the published data, such as the scan tables and the structures of every Rfam family, or help the authors with it. They work like any other command and are documented here, but firna --help does not list them, so a new user sees only the commands above. firna internal lists them. The three steps that make-assignment runs in one command are among them.

Command

Description

Input

Output

firna dataset make-seed-fasta

Writes every Rfam seed sequence to one FASTA file, each named by its family. The file is what scan-sequences searches to find which families resemble each other. firna download-data --include seed-fasta writes the same file.

Rfam.seed

data/scans/seeds.fa: every seed sequence, named family|name.

firna dataset link-families

Reads the scan of the seed sequences and links family A to family B when seed sequences of A hit the model of B, with an E-value of at most 0.01 or at the gathering threshold. Each link keeps the E-value of every sequence, so later steps can be stricter without scanning again.

Scan tables.

data/graph/family_links.tsv: links between families.

firna dataset find-components

Joins families that are linked by enough seed sequences, and the families of one Rfam clan, into components. A component is the unit that goes to one side of the split, so related families are never separated.

Links and Rfam.seed.

data/graph/components.tsv: the component of each family.

firna dataset split-components

Assigns each component to one of the splits with an integer linear program, so that the rows of each stage approach its ratios. A component is never divided, and every stage shares one label for it.

Components, sources and the dataset config.

data/dataset/assignment.tsv: the split of every unit, with the rows each source has in it.

firna structures build-alignments

Builds the seed, full and combined (seed and full) multiple sequence alignment of each family. These are the inputs to CaCoFold, and the full alignment holds the sequences that receive structures.

Rfam.seed, Rfam.full_region and the family alignments.

data/alignments/<run>/<family>/: seed, full and seed+full MSAs.

firna benchmark compare

Shows the reference structure and each predicted structure together on every chain, to inspect where predictions differ.

An evaluate-consensus run.

Stockholm files that show each structure on each chain.

firna benchmark find-missing-residues

Finds the residues of each RNA3DB chain that have no atoms in the 3D structure. Their pairing is unknown, so scoring leaves them out.

RNA3DB annotations and mmCIF files.

data/missing_residues.tsv: the residues of each chain without atoms.
