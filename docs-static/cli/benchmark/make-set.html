firna benchmark make-set#

Choose the reference RNAs to evaluate, and the part of each one to score.

Synopsis#

firna benchmark make-set [options]

Description#

Some residues of an RNA3DB chain were not resolved in its 3D structure. Their pairing is unknown, so they must not count for or against a prediction. This command finds them and writes a benchmark set that firna benchmark evaluate-consensus reads, by default from data/benchmark_set.tsv. The set’s run record also names the reference structures and the subset it was made from, so evaluate-consensus takes them from the set and they are chosen once, here.

Missing residues#

With --missing-residues, a table written by firna benchmark find-missing-residues, a residue is missing when it has no atoms in the PDB’s mmCIF file. A chain the table lacks is left out. This is the exact rule and should be used whenever the mmCIF files are available.

Without it, missing bases are guessed from the RNAview annotation. A base counts as missing when it is : in every RNAview layer, or, with --colon-only, when it is : in the secondary layer. In WUSS, : marks an unpaired base outside every helix, so the guess finds missing ends but cannot see missing residues inside a loop, which WUSS writes as _, - or ,. On a sample of 201 chains, the guess missed 56% of the residues without atoms and chose the wrong window for 36% of the chains.

Scoring window#

The scoring window runs from the first to the last residue that is not missing, so missing residues at the 5′ and 3′ ends fall outside it and are not scored. An RNA is left out of the benchmark set when:

Reason

Option

A run of missing residues inside the window is at least this long

--min-gap (default 3). --min-gap 1 leaves out any gap inside.

Every residue is missing

The window’s secondary structure has fewer base pairs than this

--min-pairs

--missing-residues has no record of the chain, or a record of another length

Every base of a table of known structures, such as ArchiveII’s, is known, so each of its RNAs is kept whole, unless --min-pairs leaves it out.

Options#

Option

Default

Description

--reference-structures PATH

sequences with known structures: an RNA3DB annotation folder, ArchiveII’s parquet file or a reference table (default: data/annotations)

--subset FAMILY

use only reference RNAs with these family labels, for sources with a family column

--out OUT

benchmark set table to write (default: data/benchmark_set.tsv)

--dropped DROPPED

also write the RNAs left out, with the reason for each

--missing-residues TABLE

table from firna benchmark find-missing-residues giving each chain’s residues without atoms; chains it lacks are left out

--min-gap MIN_GAP

3

leave out RNAs with this many missing bases in a row inside the scoring window (default: 3)

--min-pairs MIN_PAIRS

leave out RNAs with fewer base pairs than this in the scoring window

--colon-only

without –missing-residues, count every ‘:’ in the secondary structure as missing, even if another RNAview layer records an interaction for that base

--data-dir DIR

data folder used for every default path (default: $FIRNA_DATA, else ./data); paths given as options always win

--overwrite

replace the output if it already exists

--dry-run

print what would be read and written, then exit without writing anything

Output#

The benchmark set is a tab-separated table:

Column

Description

name

RNA name, such as 8y7e_H

scoring_start

First position of the scoring window, 1-based

scoring_end

Last position of the scoring window, 1-based and inclusive

 
name	scoring_start	scoring_end
10px_1A	5	2905
8y7e_H	34	51

With --dropped, the RNAs left out are written with the columns name and reason, for example 9vku_E 4 missing bases at 42-45. The command prints the number left out for each kind of reason.

Examples#

The strict benchmark set, with exact missing residues, no gaps inside and at least one base pair:

firna benchmark find-missing-residues
firna benchmark make-set --missing-residues data/missing_residues.tsv --min-gap 1 --min-pairs 1 --out data/benchmark_set_strict.tsv --dropped data/benchmark_set_strict_dropped.tsv
firna benchmark evaluate-consensus --families all --hits-table data/scans/rna3db.tbl --benchmark-set data/benchmark_set_strict.tsv --min-coverage 0.95

The earlier benchmark set, with missing bases guessed from the annotations:

firna benchmark make-set --dropped data/benchmark_set_dropped.tsv
