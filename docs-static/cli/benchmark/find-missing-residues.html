firna benchmark find-missing-residues#

Find each RNA3DB chain’s residues that have no atoms, from the PDB’s mmCIF files.

Synopsis#

firna benchmark find-missing-residues [options]

Description#

A residue is missing when its chain’s full sequence lists it but no atom in the 3D structure belongs to it. This is the rule of the RNA3DB parser. A missing residue’s pairing was never observed, so firna benchmark make-set --missing-residues leaves it out of scoring.

Each mmCIF file records the full sequence of each entity (_entity_poly_seq) and every atom (_atom_site). Chains are named by their author chain ID, as RNA3DB names are, such as 9vku_E for chain E of entry 9vku. Positions are 1-based in the full sequence, which is how RNA3DB annotations are numbered. A residue counts as present if it has any atom, in any alternative conformation.

The chains are those in the RNA3DB annotation folder. Each entry’s file is read once from --mmcif-dir, as <entry>.cif.gz or <entry>.cif. The files are the RCSB mmCIF files of the PDB entries behind the annotations. Reading the files needs the gemmi package, which environment.yml installs.

Options#

Option

Default

Description

--reference-structures PATH

RNA3DB annotation folder naming the chains (default: data/annotations)

--mmcif-dir MMCIF_DIR

folder of <entry>.cif.gz files (default: data/mmcif)

--out OUT

table to write (default: data/missing_residues.tsv)

--not-found NOT_FOUND

also write the chains that could not be found, with the reason for each

--data-dir DIR

data folder used for every default path (default: $FIRNA_DATA, else ./data); paths given as options always win

--overwrite

replace the output if it already exists

--dry-run

print what would be read and written, then exit without writing anything

Output#

A tab-separated table with one row per chain found:

Column

Description

name

Chain name, such as 9vku_E

length

Length of the chain’s full sequence

missing

Missing 1-based positions and ranges, separated by commas; empty if none are missing

 
name	length	missing
1ivs_D	75
9vku_E	188	42-45,156-166,179-188

A chain is not found when its entry has no mmCIF file, or the file has no chain with its author chain ID. The command prints how many chains were found, how many of them have missing residues, and the reasons the others were not found.

Examples#

firna benchmark find-missing-residues --not-found data/missing_residues_not_found.tsv

from firna.api import find_missing_residues, read_missing_residues, window_around_missing

missing, not_found = find_missing_residues(['9vku_E'], 'data/mmcif')
missing = read_missing_residues('data/missing_residues.tsv')
window_around_missing(missing['9vku_E'], min_gap=1)   # (None, '4 missing bases at 42-45')
