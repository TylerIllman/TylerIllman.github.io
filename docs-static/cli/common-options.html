Common options#

Family selection#

A command that works on several families takes one family as a positional argument, or several with --families. The option accepts any combination of the following selectors.

Selector

Selects

RF00005

One family.

5

One family, the same as RF00005.

all

Every available family.

30-3000

RF00030 to RF03000, inclusive.

30-

RF00030 and every later accession.

-30

RF00001 to RF00030.

A range refers to accession numbers. The selectors are matched against the families that the command can process. For firna structures build-alignments these are the families that have a full alignment in data/rfam/families/. For firna structures run-cacofold they are the families that have built alignments. For firna benchmark evaluate-consensus they are the families that have significant hits in the scan table. --list-families prints the selected families and exits.

Execution#

Option

Description

--workers N

The number of families processed at the same time, each in its own process. The default is 1.

--resume

Skips the work that is already complete.

--verbose

Prints a Start: line when each family begins, and the full traceback of each failure.

--data-dir PATH

The data folder. The default is the value of FIRNA_DATA, otherwise ./data.

A family that fails does not stop the other families. Each failure is reported when it occurs, and the failed families are listed when the run ends. The exit status is non-zero if any family failed.
