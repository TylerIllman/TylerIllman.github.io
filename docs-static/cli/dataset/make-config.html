firna dataset make-config#

Write the dataset config: the files of structures the dataset is made of, how each stage is split, and the row filters.

Synopsis#

firna dataset make-config --source STAGE:NAME=PATH[,scan=TABLE] [--source ...]
                          [--splits NAME,NAME,...] [--ratios STAGE=A:B:C ...] [filter options]
                          [--dataset-config PATH] [--overwrite]

Description#

A source is a file of sequences with their structures. It is written STAGE:NAME=PATH, with ,scan=TABLE after the path for reference structures. All sources are given in one command, and the command writes the whole config. The config is the one place the sources are listed: make-assignment and build read it, and nothing adds to it afterwards. To change a source, edit the file, or run make-config again with --overwrite.

Part

Meaning

STAGE

Any name, made of letters, digits and -, such as pretrain, finetune or benchmark. Sources of one stage are split together, and the stages are the ones the sources name.

NAME

A name made of letters, digits, ., - and _, unique in the config. It is the name the rows carry in their source column.

PATH

A folder or a zip file that holds per-family tables named <family>.structures.tsv, such as a run of firna structures extract at data/structures/<run>, a pattern in quotes of per-MSA tables, a combined table, or reference structures such as an RNA3DB annotation folder or the table of ArchiveII.

scan=TABLE

The cmscan table that gives the rows of reference structures their families.

A run folder stands for its tables, <run>/*/*.structures.tsv, and a folder of runs such as data/structures stands for its newest run. The run that was chosen is printed, and the path written to the config names it, so a later run is never read in its place.

Any other folder that holds *.structures.tsv tables, directly or one folder down, is read as those tables, and a zip file is read the same way from the tables inside it, in any folders of the archive. The family of a table is the RF accession in its name. A folder without such tables, such as RNA3DB’s annotations, is kept as it is and read as reference structures.

In Python, a StructureTable holds sequences and structures in memory and writes such tables, as StructureTable.write(out). out is a folder or, when it ends in .zip, a zip file.

Splits and ratios#

The splits have names too, shared by every stage: train, valid and test unless --splits gives others, such as --splits train,dev,holdout. Each stage has ratios, one number for each split in the order of the splits, written 80:10:10. The numbers must sum to 100, and the command refuses ratios that do not, or that have the wrong number of numbers, saying which. A stage without --ratios has 80:10:10 for three splits, 90:10 for two and 100 for one, and with more splits every stage needs its ratios.

A source goes to a split through the ratios of its stage. To keep a source in one split, give it a stage of its own with all 100 in that split:

firna dataset make-config --source pretrain:rfam=data/structures/original \
    --source benchmark:archiveii=data/archiveii/archiveii.parquet,scan=data/scans/archiveii.tbl \
    --ratios pretrain=80:10:10 benchmark=0:0:100

Which split each row goes to is decided by firna dataset make-assignment from the family of the row, so the rows of related families are always on the same side. A stage that is only in one split therefore pulls the whole groups of its families into that split, with their rows in every other stage.

The family of a row comes from the structure table when it has one. Reference structures have no Rfam family, so their families come from a scan of their sequences against Rfam, firna scan-sequences --reference-structures PATH. The scan is looked for in data/scans/<source file name>.tbl, and scan= names another. It does not have to exist yet, and the command prints the scan to run. A row with no hit in the scan is split on its own.

The config is written to data/dataset/dataset-config.json, or to the file given with --dataset-config. Paths are saved as absolute paths. A config that exists is not replaced unless --overwrite is given.

Editing the config by hand#

The file is plain JSON, described under the dataset config, and may be edited directly. make-assignment and build check it before they read anything, and report every problem at once with the source it belongs to:

  • a setting that does not exist, such as a mistyped max_lenght;

  • a source without a name or a path, or two sources with the same name;

  • ratios that are not written train:valid:test;

  • a path that does not exist, or a pattern that matches no table;

  • a reference source whose scan table is missing.

Options#

Option

Default

Description

--source STAGE:NAME=PATH[,scan=PATH]

a file of structures and the stage it is used for, such as pretrain:rfam=data/structures/<run>; repeat it for every source

--splits NAME,NAME,...

the names of the splits, shared by every stage (default: train,valid,test)

--ratios STAGE=A:B:C

how a stage’s rows are shared between the splits, one number for each split summing to 100, such as pretrain=90:5:5 (default: 80:10:10 for three splits, 90:10 for two)

--max-length N

leave out sequences longer than N, 0 for no limit (default: 1000)

--min-length N

leave out sequences shorter than N (default: 20)

--min-pairs N

leave out structures with fewer base pairs (default: 1)

--dedup

drop a row whose sequence and structure repeat an earlier row of the same family

--member-evalue E

the largest E-value of a scan hit that gives a reference structure its family (default: 0.01)

--dataset-config PATH

where to write the config (default: data/dataset/dataset-config.json)

--overwrite

replace a config that exists

--data-dir DIR

data folder used for every default path (default: $FIRNA_DATA, else ./data); paths given as options always win

Output#

data/dataset/dataset-config.json, or the file given with --dataset-config.

Examples#

firna dataset make-config \
    --source pretrain:rfam=data/structures/original \
    --source finetune:rna3db=data/annotations,scan=data/scans/rna3db.tbl \
    --source finetune:archiveii=data/archiveii/archiveii.parquet,scan=data/scans/archiveii.tbl

The ratios of one stage and the filters are set in the same command:

firna dataset make-config --source pretrain:rfam=data/structures \
    --ratios pretrain=90:5:5 --max-length 500

In Python the same is done with builder.make_config(sources, ratios=None, filters=None), where each source is written as above.
