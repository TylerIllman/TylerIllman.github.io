firna dataset make-assignment#

Make the assignment of a dataset from a scan of the Rfam seed sequences, in one command.

Synopsis#

firna dataset make-assignment [--scan TABLE ...] [--link-evalue E] [--min-fraction F | --min-sequences N] [--no-clans] [options]

Description#

The assignment says which split every unit of the dataset goes to, so that related RNA families are never on different sides. This command makes it from the scan of the Rfam seed sequences and the dataset config, and it is the command-line counterpart of the website’s builder, which makes the same table from the same settings.

It does three things in order, each of which is also available as an internal command and as a step of DatasetBuilder:

  1. link-families turns the scan into links between families. A seed sequence of family A that hits the model of family B is a link from A to B. The links keep every hit up to the E-value of 10 that cmscan reports, so the choice of how strict to be is made in the next step and can be changed without making them again.

  2. find-components joins the families that are linked by enough seed sequences, and the families of one Rfam clan, into components. A link counts when its E-value is at most --link-evalue and when either at least the share --min-fraction or at least --min-sequences of the source family’s seed sequences hit the target. --no-clans leaves the clans out.

  3. split-components gives each component one of the splits with an integer linear program, so that the rows of every stage approach the ratios of the dataset config. A component is never divided.

A step whose output was made from the same inputs and settings is kept, and a different one is refused until --overwrite is given, which replaces only that step. Changing --link-evalue, --min-fraction, --min-sequences or --no-clans therefore joins the components and splits them again without reading the scan again.

The settings the families were linked and grouped with are written at the top of assignment.tsv, in a line that starts with # linking:, so the table says how it was made. The website writes the same line. Both are read by firna dataset build, which ignores it.

The dataset config comes first: firna dataset make-config lists the sources, the stages and their ratios, and the row filters, and this command reads them from it. With --dataset-config the assignment is written beside that config.

Options#

Option

Default

Description

--dataset-config DATASET_CONFIG

the dataset config, its stages, sources, ratios and filters (default: data/dataset/dataset-config.json); when it is given, the assignment, manifest and rows are written beside it

--scan TABLE

one or more cmscan tables of the Rfam seed sequences named family|name, such as every chunk of a scan; a quoted pattern like ‘data/scans/seeds-rfam.chunk-*.tbl’ is expanded by this command (default: data/scans/seeds-rfam.tbl)

--criterion CRITERION

evalue

which hits link two families: evalue for an E-value of at most –link-evalue, or ga for a bit score at least the target family’s gathering threshold (default: evalue)

--link-evalue E

with –criterion evalue, the largest E-value of a seed hit that counts, at most 10 (default: 0.01)

--min-fraction F

0.2

the share of the source family’s seed sequences that must hit the target for a link to join two families, above 0 and at most 1 (default: 0.2)

--min-sequences N

join two families when at least this many of the source family’s seed sequences hit the target, however large the family is, instead of a share of them

--no-clans

do not join the families of an Rfam clan (default: every family of a clan is joined)

--cm CM

Rfam.cm, for the gathering thresholds (default: data/rfam/Rfam.cm)

--rfam-seed RFAM_SEED

Rfam.seed, for the list of families and their clans (default: data/rfam/Rfam.seed)

--time-limit SECONDS

60

how long the solver may improve the split (default: 60)

--seed SEED

0

changes which of several equally good splits is chosen (default: 0)

--out OUT

assignment table to write (default: data/dataset/assignment.tsv)

--data-dir DIR

data folder used for every default path (default: $FIRNA_DATA, else ./data); paths given as options always win

--overwrite

replace the output if it already exists

--dry-run

print what would be read and written, then exit without writing anything

Input#

The scan of the Rfam seed sequences, data/scans/seeds-rfam.tbl, which firna download-data --include scans downloads, or the tables of a scan made with firna scan-sequences. Rfam.seed, for the families and their clans, and Rfam.cm with --criterion ga. The dataset config and the files of structures it names.

Output#

data/dataset/assignment.tsv, described under split-components, with the links table data/graph/family_links.tsv and the components table data/graph/components.tsv that it was made through.

Examples#

firna dataset make-assignment                                      # the default rule: a share of 0.2, E-value 0.01, clans joined
firna dataset make-assignment --min-sequences 1 --link-evalue 0.01  # one seed sequence at E-value 0.01 joins two families
firna dataset make-assignment --criterion ga                       # the gathering threshold instead of an E-value
firna dataset make-assignment --scan 'data/scans/seeds-rfam.chunk-*.tbl' --no-clans
firna dataset make-assignment --link-evalue 1 --overwrite           # a looser rule, joined again from the same links
firna dataset make-assignment --dry-run
