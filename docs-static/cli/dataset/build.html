firna dataset build#

Write the dataset as parquet files, by stage and split.

Synopsis#

firna dataset build [options]

Description#

The rows of every source in the dataset config that pass the row filters are written once, one file per family, and then collected into one file per stage and split, named <stage>_<split>.parquet. The split of each row comes from the assignment, data/dataset/assignment.tsv or the file given with --assignment, which firna dataset make-assignment writes and the website can also give. build checks the assignment against the dataset config before it reads a row: the assignment must have a column for every source of the config and for no other, and every split in it must be one of the config’s. A row whose unit is not in the assignment stops the build, because the sources changed since the assignment was made. The sources and the filters are in the dataset config, which this command reads and does not change. This is a stage: its output is manifest.json, and the family and split files are replaced by each build.

The dataset config#

The dataset config, data/dataset/dataset-config.json, is written by firna dataset make-config and read by split-components and build, which check it first. It can also be edited by hand or by a script.

{
  "splits": ["train", "valid", "test"],
  "stages": {
    "pretrain": {"ratios": "80:10:10",
                 "sources": [{"name": "rfam", "path": "/data/structures/original/*/*.structures.tsv"}]},
    "finetune": {"ratios": "80:10:10",
                 "sources": [{"name": "archiveii", "path": "/data/archiveii/archiveii.parquet",
                              "scan": "/data/scans/archiveii.tbl"}]}
  },
  "filters": {"max_length": 1000, "min_length": 20, "max_ambiguous": 0.01,
              "min_pairs": 1, "dedup": false},
  "member_evalue": 0.01
}

Setting

Default

Meaning

splits

train, valid, test

The names of the splits, shared by every stage. Names use letters, digits and -.

stages

none

The stages, each with any name. A stage’s ratios have one number for each split and sum to 100, and its sources are split together. A source goes to a split through its stage’s ratios.

max_length, min_length

1000, 20

Bounds on the sequence length. 0 turns a bound off.

max_ambiguous

0.01

The largest fraction of bases other than A, C, G and U.

min_pairs

1

The fewest base pairs the structure may have.

dedup

false

Drop a row whose sequence and structure repeat an earlier row of the family.

member_evalue

0.01

The largest E-value of a scan hit that gives a reference structure its family.

Several datasets in one data folder#

--dataset-config PATH makes make-config, split-components and build use that dataset config, and the split table, manifest.json, rows/ and the stage and split files are written in its folder. Each folder is therefore a complete dataset, and two of them do not overwrite each other. The components table is shared, because it depends only on the links, unless --components names another.

firna dataset make-config --dataset-config data/datasets/a/dataset-config.json \
    --source pretrain:rfam=data/structures/original \
    --source finetune:archiveii=data/archiveii/archiveii.parquet \
    --ratios pretrain=90:5:5
firna dataset split-components --dataset-config data/datasets/a/dataset-config.json
firna dataset build --dataset-config data/datasets/a/dataset-config.json

Options#

Option

Default

Description

--dataset-config DATASET_CONFIG

the dataset config, its stages, sources, ratios and filters (default: data/dataset/dataset-config.json); when it is given, the assignment, manifest and rows are written beside it

--assignment ASSIGNMENT

assignment table from firna dataset split-components (default: data/dataset/assignment.tsv), which may also come from the website; its source columns must match the dataset config

--out OUT

manifest to write (default: data/dataset/manifest.json)

--data-dir DIR

data folder used for every default path (default: $FIRNA_DATA, else ./data); paths given as options always win

--overwrite

replace the output if it already exists

--dry-run

print what would be read and written, then exit without writing anything

Output#

File

Content

dataset/rows/family=<family>/part-N.parquet

The rows of one family, with the columns name, sequence, structure, component, source, stage and split. Rows with no Rfam family are in family=unmatched.

dataset/<stage>_<split>.parquet

The rows of one stage and split, such as pretrain_train.parquet or finetune_test.parquet, with family as an extra column. A file is written only when it has rows.

dataset/manifest.json

The dataset config, the rows in each stage and split, how many rows each filter left out, and the files.

Examples#

firna dataset build
firna dataset build --dry-run

import pyarrow.dataset as ds
rows = ds.dataset('data/dataset/rows', format='parquet', partitioning='hive')
tRNA = rows.to_table(filter=ds.field('family') == 'RF00005')
