firna structures build-alignments#

Build the experiment MSAs for each family from Rfam’s existing alignments.

Synopsis#

firna structures build-alignments --families SELECTOR ... [options]
firna structures build-alignments --families SELECTOR ... [options]

Description#

Builds the following MSAs without realigning any sequence. Every MSA keeps the columns of Rfam’s alignments, so all share the same consensus columns.

MSA

Contents

seed

The seed alignment.

full

An exact copy of the full alignment.

seed_full

Seed and full alignments merged with Easel. Where a sequence ID occurs in both, the seed row is kept.

filtered

Full rows whose E-value in Rfam.full_region is below --evalue (default 0.01), limited to --max-sequences rows when that is given. Built only when requested.

The seed, full and seed_full MSAs have no E-value filter or size limit, so a large family’s full MSA holds every hit Rfam reports for it. With --max-sequences N, rows are drawn at random from those that pass --evalue, with a fixed seed, so that the same rows are drawn every time. manifest.json records the E-value, the limit and how many rows passed before the limit.

Each run writes to its own folder, data/alignments/<run>/, named after the start time unless --run NAME gives a name. Jobs that share a name write into the same run, as the jobs of a batch array do. With --resume and no --run, the newest run is continued.

Each family is built in a temporary directory and moved into place only when complete, so an interrupted run never leaves a partial family folder. An existing family folder is never overwritten. Without --resume, such a family is reported as failed. With --resume, it is skipped if it contains exactly the requested MSAs, and the run stops if it contains a different set.

Options#

Option

Default

Description

--families FAMILIES

accessions, all, 30-3000, 30-, or -30; ranges use local full alignments

--workers WORKERS

1

parallel family processes (default: 1)

--list-families

print selected local family accessions, one per line, without building

--resume RUN

continue a run, the newest one without RUN, or RUN given as a name in data/alignments/ or a path: skip complete matching alignments and reject incomplete ones

--verbose

log each family as it starts and print full tracebacks for failures

--run RUN

name of the run folder to write into, made if new (default: the start time)

--full-alignment FULL_ALIGNMENT

override the input full Stockholm file

--out OUT

exact directory for one family; parent directory for multiple families (default: data/alignments/<run>/<family>)

--evalue EVALUE

0.01

for filtered: keep full rows with an E-value below this (default: 0.01)

--max-sequences N

for filtered: keep at most N rows, drawn at random with a fixed seed from those that pass –evalue (default: no limit)

--evalue-match EVALUE_MATCH

id

for filtered: match full_region by exact ID, or also by identical sequence

--include INCLUDE

seed full seed_full

MSAs to build; default: seed full seed_full. Add filtered explicitly.

--data-dir DIR

data folder used for every default path (default: $FIRNA_DATA, else ./data); paths given as options always win

--families is required.

Input#

File

Required for

data/rfam/families/<family>/<family>.sto

all MSAs

data/rfam/families/<family>/<family>.seed.sto

seed MSAs; data/rfam/Rfam.seed is used if absent

data/rfam/Rfam.full_region

filtered

Output#

data/alignments/<run>/<family>/
├── seed.sto
├── full.sto
├── seed_full.sto
└── manifest.json

The run folder also holds a run.json, which marks it as a run.

manifest.json records the input files and their checksums, the row count of each MSA, and how each MSA was constructed.

Examples#

firna structures build-alignments --families RF00005
firna structures build-alignments --families all --workers 8
firna structures build-alignments --families all --workers 8 --resume
firna structures build-alignments --families all --workers 8 --run rfam-15
firna structures build-alignments --families RF00005 --include seed full seed_full filtered --evalue 1e-5 --max-sequences 5000
firna structures build-alignments --families 30-3000 --list-families
