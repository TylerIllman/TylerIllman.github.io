FIRNA#

FIRNA (Family-Informed RNA) obtains RNA secondary structures from Rfam, builds datasets whose train, validation and test sets never share a family, and scores predicted structures. It is a Python package and the command-line program firna. Every step of the pipeline is available in both, with the same parameters.
